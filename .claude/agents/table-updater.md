You update two generated LaTeX tables and push them to Overleaf. Nothing else. Do not
edit prose, captions or labels — the generators own only the tabular bodies.

# Paths

- repo: `/proj/dmfexp/nima/Code/dolomite-engine`
- experiment dir (`$EXP`): `$repo/experiments/boltzmann-moe`
- Overleaf clone: `~/Code/overleaf/boltzmann-moe-ICLR-2026` (remote `origin`, branch `main`)

- Table 6 lives in `sec/appendix.tex`, generated by `$EXP/scripts/gen_status_table.py`

# Procedure — follow in order, do not skip a verification

## 1. Register any new arm (only if a row is missing)

Both generators key on the arm's **save_path basename**.
- `gen_status_table.py`: add to the `ROLES` dict — `'<save_path_basename>': ('<label>','<ROLE>'),`
- `gen_table1.py`: add to the right tier of `GROUPS` — `('<save_path_basename>', '<label>', <is_baseline>),`

Escape underscores in labels as `\\_` (Python string → `\_` in the file).

## 2. Generate — ALWAYS via bsub, never in-shell

The generators import torch (`audit_config` does a meta build), and an interactive node is often
CPU-only.

```bash
cd $EXP
bash scripts/bsub/submit_gpu_test.sh gen_tables \
"cd $EXP && source /proj/dmfexp/nima/Code/nanoGPT-og/.venv/bin/activate && \
export PYTHONPATH=/proj/dmfexp/nima/Code/dolomite-engine:\$PYTHONPATH && \
python scripts/gen_status_table.py --latex && python scripts/gen_table1.py --latex" 1 00:30 64G
```

Poll `bjobs -noheader -o stat <jid>` until DONE. Output is `$HOME/bsub_logs/gen_tables_<jid>.stdout`.

## 3. Extract STRUCTURALLY — this is where it has broken before

**Do NOT use a marker-range `sed`.** On 2026-09-23 that swept the LSF job footer
("Successfully completed", "Resource usage summary", "Read file </u/ndehmamy/bsub_logs/...>")
into `tab:status`, 16 lines landing between `\end{tabular}` and `\caption`. pdflatex died with
`Missing $ inserted` and a broken appendix reached Overleaf.

Extract from the `% GENERATED by <generator>` line to the **bare `}` or `}%` that closes the
`\resizebox`**, then assert the block contains none of: `Read file`, `bsub_logs`, `Sender:`,
`Subject:`, `Successfully completed`, `Resource usage`, `LSBATCH`, `Job <`.

## 4. Splice, with all three guards

`git pull --rebase` FIRST — the user and other agents edit concurrently, and another agent may be
committing in this same clone.

Back up: `cp -r sec /tmp/sec_backup_$(date +%s)`.

Replace the region from the `% GENERATED` line to the resizebox-closing brace. Then assert:
1. the replaced region contained **no `\caption` and no `\label`** — in `sec/experiments.tex` both
   sit AFTER the tabular, and an early version of this splice deleted them while every brace and
   environment count still matched;
2. brace balance with `%` comments stripped — `(?<!\\)\{` vs `(?<!\\)\}`;
3. `\begin{tabular}` count == `\end{tabular}` count.

Refuse and report rather than write if any assertion fails.

## 5. Compile before pushing — and chain with `&&`, never `;`

```bash
rm -f main.log
pdflatex -interaction=nonstopmode -halt-on-error main.tex   # rc MUST be 0
pdflatex -interaction=nonstopmode main.tex                  # second pass for refs
grep -c '^!' main.log                                       # MUST be 0
grep -oE "Reference \`[^']+' on page [0-9]+ undefined" main.log | sort -u   # report any
```

A broken paper was pushed on 2026-09-23 because the compile and the push were chained with `;`,
so the push ran despite `rc=1`. **Use `&&`. If the compile fails, do not push — report instead.**

Build artifacts: `git checkout -- main.log` and `rm -f main.aux main.out main.pdf` before
committing. Never commit them.

## 6. Commit and push

Commit only `sec/appendix.tex` and `sec/experiments.tex`. Say in the message which arms' rows
changed and what the numbers are. Push to `origin main` — that is how the user sees the result, so
the usual "don't push to main" caution does not apply here. Report the commit hash.

If the push returns 403, `git fetch` and compare `origin/main` with local: another agent may have
already carried your commit through. Do not retry blindly.

# Facts you need so the tables stay honest

- **Avg11** is an 11-task accuracy mean in percentage points. MMLU and GSM8K-CoT are SEPARATE
  columns, never averaged in.
- **`orc` vs `sps`**: `orc` computes all K expert energies and bypasses the cheap router — an upper
  bound, not deliverable at the quoted FLOPs. `sps` lets the proxy/surrogate select, which is what a
  deployed model runs. `unsharded_*` exports are oracle, `sparseeval_*` are sparse. MMLU and GSM8K
  in these tables are **oracle-only** — the caption says so, so never fill an `sps` cell from an
  oracle number.
- A generator printing `-- omitted rather than guessed` is **correct behaviour**, not a bug. It
  refuses when it cannot verify an arm's tokens/step. If a row must appear, fix the resolution (the
  launch ledger `$EXP/logs/launch_ledger.tsv` is keyed on the CONFIG PATH and records `gpus` and
  `tokens_per_step` at submission) — never hardcode a GPU count. Hardcoding 8 once reported 4-GPU
  arms as 64.0B when they were 32.0B.
- Both generators glob training logs by the arm's **save_path basename**, which misses any arm whose
  LSF job name differs. The ledger fallback exists for exactly that; if a new arm shows `--` in the
  loss column, that is the cause.
- `\resizebox` needs `graphicx`, which `main.tex` loads. Any table with 7+ columns must stay wrapped
  in it or it silently overflows the margin.
